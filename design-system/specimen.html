2. Spacing & radius tokens

--space-1 (.25rem)
--space-2 (.5rem)
--space-4 (1rem)
--space-8 (2rem)
--radius-sm
--radius-md

Spacing uses a fixed scale rather than arbitrary pixel values, so any two components stay visually consistent by construction.

3. Typography

Heading 1 — page title

Heading 2 — section title

Heading 3 — component title

Body text uses the humanist sans role for long-form reading, capped at a readable line length.

Only one <h1> per page. Heading level follows document outline, never visual size — size is controlled separately in CSS.

4. Component: Button

Usage: primary action per section (one .button per form/section). Use .button--secondary for a lower-emphasis action next to a primary one. Consumes --action, --action-hover, --action-text tokens. Real hover/focus-visible/active states are demonstrated by interacting with the default button directly.

5. Component: Card

Open

Sample event

Friday · 1:30 PM · PUCIT Old Campus

Hover this card to see its border pick up the action color.

Usage: semantic element is <article> — each card must be a complete, self-contained unit. Supports a .badge child with data-status of "open", "limited", or "full"; status is always paired with text, never color alone. Consumes --surface-card, --border-default, --action tokens.

6. Component: Form field

Usage: label's `for` must match input `id` — this is what makes the label clickable and gives the input an accessible name. Set data-state="success"/"error" on the .field wrapper to trigger the paired border-color + message change.
